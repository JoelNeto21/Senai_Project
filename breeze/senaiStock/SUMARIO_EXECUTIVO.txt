## ✅ VALIDAÇÕES IMPLEMENTADAS

1. ISBN Único por Livro
   → POST duplicate ISBN → 422 Unprocessable

2. Quantidade Mínima (0-max)
   → POST negative quantity → 422 Unprocessable

3. Saída Requer Justificativa
   → POST saida sem justification → 422 Unprocessable

4. Entrada NÃO Requer Justificativa
   → POST entrada sem justification → 201 Created ✓

5. Saída Bloqueada se Insuficiente
   → POST saida qty > saldo → 422 Quantity insufficient

6. Autenticação Obrigatória
   → GET /api/books sem token → 401 Unauthenticated

## 🚀 COMO EXECUTAR

1. Setup Automático (2 min)
   $ php setup_api.php

2. Instalar Sanctum (1 min)
   $ php artisan sanctum:install

3. Migrations (1 min)
   $ php artisan migrate

4. Gerar Token (30 seg)
   $ php artisan tinker
   > $user = User::find(1)
   > $user->createToken('api')->plainTextToken

5. Testar (30 seg)
   $ curl -H "Authorization: Bearer TOKEN" http://localhost/api/books

Tempo Total: ~5 minutos ⏱️
