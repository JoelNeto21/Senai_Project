┌─ CONTROLLERS API ───────────────────────────────────────────────────────────┐

✅ BookController.php
   • index(): Lista paginada de livros (15 por página)
   • show(Book): Retorna um livro específico
   • store(StoreBookRequest): Cria novo livro
   • update(UpdateBookRequest, Book): Atualiza livro
   • destroy(Book): Deleta livro
   • Retorna: BookResource
   • Criado via: setup_api.php
   • Arquivo: app/Http/Controllers/Api/BookController.php

✅ MovementController.php
   • store(StoreMovementRequest): Registra movimento
   • Validações: Via Form Request
   • Regra de Negócio: Bloqueia saida se insuficiente (422)
   • Transação: DB::transaction() para atomicidade
   • Incremento/Decremento: Atualiza quantity
   • User ID: Auth::id() automaticamente
   • Retorna: MovementResource com status 201
   • Criado via: setup_api.php
   • Arquivo: app/Http/Controllers/Api/MovementController.php

REGRAS DE NEGÓCIO - CHECKLIST

✅ Saída bloqueada se quantidade > saldo
   • HTTP: 422
   • Message: "Quantidade insuficiente em estoque"
   • Implemented in: MovementController@store

✅ Justificação obrigatória para saída
   • Validação: required_if:type,saida
   • Entrada: Justificação opcional
   • Implemented in: StoreMovementRequest

✅ Apenas usuários autenticados alteram estoque
   • Middleware: auth:sanctum
   • User ID: Auth::id()
   • Applied to: Todas as rotas de escrita

✅ Transação atômica
   • DB::transaction() implementado
   • Update quantity + Create movement
   • Atomicidade garantida

✅ Nível crítico < 10
   • Campo: is_critical_stock
   • Método: isCriticalStock() no Model
   • Retornado em: BookResource

✅ Estoque não fica negativo
   • Min: 0 nas validações
   • Decrement: Não deixa negativo
