╔══════════════════════════════════════════════════════════════════════════════╗
║ REGRAS DE NEGÓCIO IMPLEMENTADAS                                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

  ✓ Saída bloqueada se quantidade > saldo (422)
  ✓ Justificativa obrigatória para saídas
  ✓ Apenas usuários autenticados alteram estoque
  ✓ Transações atômicas para integridade
  ✓ Nível crítico quando estoque < 10
  ✓ ISBN único por livro
  ✓ Quantidade nunca negativa


╔══════════════════════════════════════════════════════════════════════════════╗
║ VALIDAÇÕES IMPLEMENTADAS                                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

  ✓ Title (required, string)
  ✓ ISBN (required, unique)
  ✓ Subject (required, string)
  ✓ Quantity (integer, min:0)
  ✓ Type (entrada|saida)
  ✓ Book ID (exists)
  ✓ Justification (required_if type=saida)

║ EXEMPLOS RÁPIDOS                                                            ║

Criar livro:
  POST /api/books
  {
    "title": "Programação em Python",
    "isbn": "978-8535-1234",
    "subject": "Programação",
    "quantity": 20
  }

Registrar entrada:
  POST /api/movements
  {
    "type": "entrada",
    "book_id": 1,
    "quantity": 5,
    "justification": "Compra fornecedor"
  }

Registrar saída (BLOQUEADA se insuficiente):
  POST /api/movements
  {
    "type": "saida",
    "book_id": 1,
    "quantity": 3,
    "justification": "Distribuição sala 101"
  }
