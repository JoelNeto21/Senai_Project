4. COMO COMEÇAR
───────────────────────────────────────────────────────────────────────────────

Passo 1 - Ler documentação:
  → 00_COMECE_AQUI.txt (este arquivo)
  → README_IMPLEMENTACAO.txt

Passo 2 - Setup automático:
  $ cd c:\laragon\www\Senai_Project\breeze\senaiStock
  $ php setup_api.php
  [Cria diretórios e arquivos da API]

Passo 3 - Instalar Sanctum:
  $ php artisan sanctum:install
  $ php artisan migrate

Passo 4 - Criar usuário de teste:
  $ php artisan tinker
  > User::create(['name' => 'Admin', 'email' => 'admin@test.com', 'password' => Hash::make('senha')])
  > exit

Passo 5 - Gerar token:
  $ php artisan tinker
  > $user = User::find(1)
  > $token = $user->createToken('api-token')->plainTextToken
  > echo $token
  > exit

Passo 6 - Testar:
  $ curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost/api/books

Tempo total: ~15 minutos

5. VALIDAÇÕES E REGRAS DE NEGÓCIO
───────────────────────────────────────────────────────────────────────────────

VALIDAÇÕES IMPLEMENTADAS:
  ✓ Title: required, string, max:255
  ✓ ISBN: required, unique:books
  ✓ Subject: required, string, max:255
  ✓ Quantity: required, integer, min:0
  ✓ Type: required, in:entrada,saida
  ✓ Book ID: required, exists:books,id
  ✓ Justification: required_if:type,saida, max:1000

REGRAS DE NEGÓCIO:
  ✓ Saída bloqueada se quantidade > saldo (HTTP 422)
  ✓ Justificação obrigatória para saída
  ✓ Entrada NÃO requer justificação
  ✓ Apenas usuários autenticados (Sanctum)
  ✓ Transação atômica: quantidade + registro
  ✓ Nível crítico quando estoque < 10

CÓDIGOS HTTP RETORNADOS:
  ✓ 200 OK (GET, PUT)
  ✓ 201 Created (POST)
  ✓ 204 No Content (DELETE)
  ✓ 401 Unauthorized (sem token)
  ✓ 422 Unprocessable Entity (validação/negócio)
