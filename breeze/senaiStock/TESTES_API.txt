## PASSO 1: Criar um Usuário e Obter Token

### A) Registrar novo usuário (POST)
URL: http://localhost/register
Método: POST
Content-Type: application/json

Body:
{
  "name": "João Silva",
  "email": "joao@example.com",
  "password": "password123",
  "password_confirmation": "password123"
}

### B) Fazer Login (POST)
URL: http://localhost/login
Método: POST
Content-Type: application/json

Body:
{
  "email": "joao@example.com",
  "password": "password123"
}

Response: Guardará o cookie de sessão

### C) Obter Token via Sanctum (via Tinker)
```bash
php artisan tinker
> $user = User::where('email', 'joao@example.com')->first();
> $token = $user->createToken('api-token')->plainTextToken;
> echo $token;
```

Copie o token retornado.

### TESTE 8: Tentar Saída com Quantidade Insuficiente (POST) - ERRO ESPERADO
URL: http://localhost/api/movements
Método: POST

Headers:
- Authorization: Bearer {seu_token}
- Accept: application/json
- Content-Type: application/json

Body:
{
  "type": "saida",
  "book_id": 2,
  "quantity": 100,
  "justification": "Tentar remover mais do que existe"
}

  "errors": {

      "A saída solicitada (100) excede o saldo disponível (12)."
    ]
  }
}

✅ REGRA DE NEGÓCIO TESTADA: Saída bloqueada quando quantidade > saldo

## COMANDOS ÚTEIS COM CURL
═══════════════════════════════════════════════════════════════════════════════════

Listar livros:
curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost/api/books

Criar livro:
curl -X POST http://localhost/api/books \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"Novo","isbn":"123","subject":"Test","quantity":5}'

Registrar movimento:
curl -X POST http://localhost/api/movements \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type":"entrada","book_id":1,"quantity":5,"justification":"test"}'
