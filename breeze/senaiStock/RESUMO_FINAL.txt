### 3️⃣ Testar Endpoints

#### A) Criar um usuário para teste:
```bash
php artisan tinker
> User::create(['name' => 'Teste', 'email' => 'teste@test.com', 'password' => Hash::make('senha123')])
> exit
```

#### B) Gerar token via Tinker:
```bash
php artisan tinker
> $user = User::find(1)
> $token = $user->createToken('api-token')->plainTextToken
> echo $token
```

#### C) Testar via curl:
```bash
# Listar livros
curl -H "Authorization: Bearer SEU_TOKEN" http://localhost/api/books

# Criar livro
curl -X POST http://localhost/api/books \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"Livro","isbn":"123-456","subject":"Programação","quantity":10}'

# Registrar entrada
curl -X POST http://localhost/api/movements \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type":"entrada","book_id":1,"quantity":5,"justification":"Compra"}'

# Registrar saída
curl -X POST http://localhost/api/movements \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type":"saida","book_id":1,"quantity":2,"justification":"Distribuição"}'
```

## 📋 REGRAS DE NEGÓCIO IMPLEMENTADAS

✅ Saída bloqueada se quantidade > saldo disponível (HTTP 422)
✅ Toda saída exige campo 'justification' obrigatório
✅ Entrada NÃO exige justificativa
✅ Apenas usuários autenticados (Sanctum) alteram estoque
✅ Transação atômica: quantidade + registro são salvos juntos ou não salvam
✅ Nível crítico: is_critical_stock = true quando quantity < 10
✅ Quantidade nunca fica negativa (min: 0)
✅ ISBN é único por livro

## 🔌 ENDPOINTS DISPONÍVEIS

### Livros
GET    /api/books              - Listar todos (paginado)
GET    /api/books/{id}         - Obter um
POST   /api/books              - Criar novo
PUT    /api/books/{id}         - Atualizar
DELETE /api/books/{id}         - Deletar

### Movimentos
POST   /api/movements          - Registrar entrada/saída

### Usuário
GET    /api/user               - Dados do usuário autenticado

## 🆘 TROUBLESHOOTING

P: "Class BookResource not found"?
R: Execute: php setup_api.php

P: "Unauthenticated" em todas as rotas?
R: Verifique:
   - Sanctum está instalado (php artisan sanctum:install)
   - User model tem trait HasApiTokens
   - Token no header: Authorization: Bearer {token}

P: "Field quantity was invalid"?
R: Verifique:
   - quantity deve ser inteiro >= 0
   - Type deve ser "entrada" ou "saida"

P: "The given data was invalid"?
R: Verifique validações em StoreBookRequest/UpdateBookRequest/StoreMovementRequest
