🚀 PARA COMEÇAR (5 MINUTOS)

Passo 1: Setup automático
  $ php setup_api.php

Passo 2: Instalar Sanctum
  $ php artisan sanctum:install

Passo 3: Migrations
  $ php artisan migrate

Passo 4: Gerar token
  $ php artisan tinker
  > $user = User::find(1)
  > $user->createToken('api')->plainTextToken

Passo 5: Testar
  $ curl -H "Authorization: Bearer TOKEN" http://localhost/api/books

Sucesso! 🎉
