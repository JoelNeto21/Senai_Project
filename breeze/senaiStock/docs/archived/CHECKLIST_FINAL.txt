┌─ CONTROLLERS API ───────────────────────────────────────────────────────────┐

✅ BookController.php
   • index(): Lista paginada de livros (15 por página)
   • show(Book): Retorna um livro específico
   • store(StoreBookRequest): Cria novo livro
   • update(UpdateBookRequest, Book): Atualiza livro
   • destroy(Book): Deleta livro
   • Retorna: BookResource
   • Criado via: setup_api.php
   • Arquivo: app/Http/Controllers/Api/BookController.php

✅ MovementController.php
   • store(StoreMovementRequest): Registra movimento
   • Validações: Via Form Request
   • Regra de Negócio: Bloqueia saida se insuficiente (422)
   • Transação: DB::transaction() para atomicidade
   • Incremento/Decremento: Atualiza quantity
   • User ID: Auth::id() automaticamente
   • Retorna: MovementResource com status 201
   • Criado via: setup_api.php
   • Arquivo: app/Http/Controllers/Api/MovementController.php
