Implementação SenaiStock - Instruções Finais

⚠️ Passos Necessários Para Completar a Implementação:

IMPORTANTE: A ferramenta de PowerShell não está disponível no ambiente. Você precisa executar estes comandos manualmente no seu terminal/CMD:

1️⃣ Criar Diretórios Necessários (executar no CMD/Terminal):

mkdir c:\laragon\www\Senai_Project\breeze\senaiStock\app\Http\Controllers\Api
mkdir c:\laragon\www\Senai_Project\breeze\senaiStock\app\Http\Resources

2️⃣ Ou use PHP direto:

cd c:\laragon\www\Senai_Project\breeze\senaiStock
php bootstrap_dirs.php

3️⃣ Copiar os arquivos criados para os locais corretos:

Arquivo 1: BookResource.php

De: app/Http/Requests/INSTRUCTIONS_BookResource.txt

Para: app/Http/Resources/BookResource.php

Arquivo 2: MovementResource.php

De: app/Http/Requests/INSTRUCTIONS_MovementResource.txt

Para: app/Http/Resources/MovementResource.php

Arquivo 3: BookController.php

De: app/Http/Requests/INSTRUCTIONS_BookController.txt

Para: app/Http/Controllers/Api/BookController.php

Arquivo 4: MovementController.php

De: app/Http/Requests/INSTRUCTIONS_MovementController.txt

Para: app/Http/Controllers/Api/MovementController.php

4️⃣ Executar Migrations e Seeders:

php artisan migrate
php artisan db:seed (opcional)

5️⃣ Configurar Sanctum (se não estiver configurado):

php artisan sanctum:install
php artisan migrate

6️⃣ Adicionar rotas em routes/api.php:

Ver arquivo: SETUP_ROUTES_API.txt

7️⃣ Corrigir CargoController.php

Ver arquivo: SETUP_CARGO_CONTROLLER_FIX.txt

8️⃣ Adicionar HasApiTokens ao User Model:

Ver arquivo: SETUP_USER_MODEL.txt
